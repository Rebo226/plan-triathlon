# Plan Triathlon

Aplikacja (PWA) z planem treningowym do triathlonu: rower i pływanie rozpisane, bieg z Garmin Coach, siła w domu (KB 12 kg), mobilność, starty A/B/C, testy FTP/CSS, postęp i prognozy, eksport do PDF A4.

Instalacja: otwórz stronę w Chrome (Android) lub Safari (iPhone) → „Dodaj do ekranu głównego”.
Dane są zapisywane tylko na urządzeniu – kopię zrobisz w zakładce Dane → Kopia danych.
